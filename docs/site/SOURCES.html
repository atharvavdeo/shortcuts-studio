Primary sources and authority

Reviewed 13 October 2026. These are primary references for guidance and public interfaces, not proof that our app passed a vendor review. Some Apple documentation requires JavaScript; available text, published documentation JSON and the installed public SDK interfaces were used. Local source/tests remain the authority for Studio behavior.

Apple design

  • Human Interface Guidelines: platform design principles; apply relevant guidance by surface/platform.
  • Accessibility: input, perception and assistive interaction.
  • Toolbars: command/menu access and native presentation.
  • Color: semantic and custom appearance/contrast.
  • Keyboards: familiar modifier/shortcut behavior.
  • Focus and selection: visible, platform-consistent focus.
  • App icons: original identity, modern layers and accepted flat artwork.
  • Icon Composer: layered icon authoring; full asset work remains pending.

Apple API and distribution

  • SwiftUI, AppKit, Foundation: public frameworks used by this source.
  • Defining file/data types: UTI export and JSON conformance.
  • Privacy manifests, required-reason APIs: declarations must match actual use and affected platform.
  • Preparing distribution: signing, hardened runtime, sandbox applicability and metadata.
  • Notarizing macOS software: Developer ID/timestamp/hardened runtime/notary workflow.
  • App Review Guidelines: accurate functionality, public APIs, originality and channel-specific review.
  • Foundation Models, WWDC25 introduction: system on-device model/session/guided generation and streaming.
  • Local-network privacy: macOS identity/permission handling and Bonjour declarations.
  • NWListener, TLS parameters: proposed network transport primitives, not a complete implemented server.

The installed macOS 27 SDK declarations were inspected for FoundationModels, AppKit and file/system APIs. The CLT SDK was not modified. Swift code snippets either correspond to actual implementation or are clearly labeled insertion/example/proposal code.

Apple Shortcuts comparison

  • CLI execution: supported bridge and prompt behavior.
  • Variables: Apple's richer value/content model.
  • Sync: documented cross-device iCloud synchronization.
  • Intelligent actions on iPhone/iPad: Apple's model capabilities; availability is platform/version dependent.

These sources establish feature context. No matched benchmark or original-app usability study was performed.

Android proposal

  • Local network permission: Android 16 opt-in/Android 17 target SDK 37 enforcement and user-mediated NSD alternatives; recheck before implementation.
  • Android Keystore: device credential/key storage.
  • Network security configuration: transport trust policy; do not globally bypass TLS.
  • BLE background communication: constraints if BLE/companion services are adopted; not a Wi-Fi exemption.

Refresh policy

Recheck platform guidance when the OS/SDK/target SDK, distribution channel, data use, third-party dependencies or remote protocol changes. Record the retrieval date and relevant test artifact. A source URL in this list is not an Apple/Google endorsement of Shortcut Studio.
